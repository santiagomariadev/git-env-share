# Project Development Instructions

- Follow docs/AI_CONTRIBUTOR_GUIDE.md and docs/DEVELOPMENT.md.
- Treat the guides as the source of truth.
- Before implementing anything, inspect the existing architecture.
- Never implement multiple unrelated features in a single task.
- Follow existing coding conventions.
- Do not introduce dependencies without justification.
- Run relevant tests after modifications.
- Never claim a task is complete without verifying it.

## Workflow

1. Read the contributor and development guides.
2. Identify the current implementation status.
3. Propose an implementation plan.
4. Wait for approval.
5. Implement one logical task at a time.
6. Run tests and report the results.
7. Update the development checklist.
